🏥 Website - Clínica Médica Vida & Saúde

Este é um projeto simples de um site institucional para uma clínica médica, desenvolvido exclusivamente em HTML5 puro, estruturado em múltiplas páginas interligadas através de navegação interna.

📁 Estrutura de Arquivos

Para que a navegação entre as páginas funcione corretamente, todos os arquivos .html e o arquivo README.md devem estar salvos na mesma pasta raiz:

clinica-medica/
│
├── index.html          # Página Principal (Início)
├── especialidades.html # Página de Especialidades Médicas
├── horario.html        # Página de Horários de Atendimento e Contactos
├── localizacao.html    # Página de Localização e Mapa Interativo
└── README.md           # Documentação do Projeto


🌐 Funcionalidades das Páginas

1. index.html (Início)

Apresentação da clínica com mensagem de boas-vindas.

Imagem do consultório médico.

Menu de navegação principal.

Lista de diferenciais do atendimento.

2. especialidades.html (Especialidades)

Apresentação dos serviços médicos prestados (Cardiologia, Dermatologia, Pediatria, Ortopedia, Clínica Geral).

Links externos para direcionamento com informações detalhadas de cada especialidade.

3. horario.html (Horários & Contactos)

Tabela responsiva com horários de atendimento (<table>, <tr>, <th>, <td>).

Informações diretas de contacto (Telefone, WhatsApp e E-mail) com links acionáveis (tel:, mailto: e link para WhatsApp).

4. localizacao.html (Localização)

Endereço físico e pontos de referência.

Mapa interativo do Google Maps incorporado via <iframe>.

🚀 Como Executar o Projeto

Baixe ou copie todos os arquivos (.html) para uma mesma pasta em seu computador.

Abra qualquer um dos arquivos .html (recomendado: index.html) dando um duplo clique.

O projeto abrirá diretamente em seu navegador web (Google Chrome, Mozilla Firefox, Edge, Safari, etc.).

Utilize o menu no cabeçalho para navegar entre as diferentes seções.

🛠️ Tecnologias Utilizadas

HTML5: Estrutura semântica das páginas (<header>, <nav>, <main>, <section>, <footer>, <table>, <iframe>).

Google Maps Embed API: Exibição do mapa interativo.

Desenvolvido em 2026 para fins educacionais e demonstrativos.
